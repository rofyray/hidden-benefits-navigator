# P2-01 — Local model adapter

Date: 2026-09-19

## Changed paths

- `src/client/adapters/nano.ts` — new: typed capability/setup/session adapter over the
  Chrome Prompt API (`LanguageModel`), with download progress, cancellation and
  destruction.
- `src/routes/preflight.tsx` — the device-check page now drives setup through the
  adapter: one explicit setup action, a "Stop the setup" control, and every session
  released when the page unmounts.
- `tests/unit/nano-adapter.test.ts` — new: 22 unit tests against a fake browser
  global (no real model download, no personal text).

## What the adapter guarantees

- **Isolated globals.** Only this module and the capability probe touch
  `LanguageModel`. Callers see `probe()`, `createSession()`, `destroyAll()`,
  `subscribe()` and a `LocalModelSession` with `prompt()`/`destroy()`.
- **Distinct states, independent of speech.** `unsupported`, `unavailable`,
  `downloadable`, `downloading`, `available`, `unknown`. An unrecognised or missing
  availability value maps to `unknown`, never optimistically to available; a probe
  that throws yields `unknown` rather than being read as absence. Speech,
  microphone and playback remain separate probes in `capabilities.ts`.
- **Intentional setup only.** `createSession` requires `requestedByUser: true`;
  without it the call fails with `local_setup_not_requested` and `create()` is never
  reached, so no render path can begin a model download.
- **Same options for check and create.** `LOCAL_MODEL_OPTIONS` is used by both, as
  the Prompt API documentation requires.
- **Separate sessions per purpose.** `purpose: "extraction" | "explanation"` keeps a
  personal narrative out of any explanation context.
- **Cancellation everywhere.** An already-aborted signal short-circuits before
  creation and before prompting; an abort mid-creation destroys the session that
  arrives late; an aborted prompt reports `local_cancelled`, never a model failure.
- **Typed failures.** `LocalModelError` with `local_unsupported`,
  `local_unavailable`, `local_setup_not_requested`, `local_session_failed`,
  `local_session_destroyed`, `local_prompt_failed`, `local_cancelled`.
- **Fails closed on shape.** A session object without `prompt()`, or a prompt result
  that is not a string, is an error — never passed on as data.
- **No stalls from third-party failures.** A throwing subscriber or a throwing
  browser-side `destroy()` cannot take the adapter down; `destroy()` is idempotent.
- **No personal data.** Prompt text is passed through and never retained, logged or
  emitted in an event; events carry only state, progress and session counts.

## Limitations

- A device with the model actually present has not been exercised: this sandbox
  browser does not ship the Prompt API, so `downloadable`/`downloading`/`available`
  paths are covered by unit tests against a fake global only. The real-device setup
  check must be repeated on the demo device, on the final origin and profile.
- The adapter exposes prompting; schema authoring, validation of parsed output and
  the retry/manual-fallback policy belong to P2-02 and are not implemented here.
- Generation timeouts (5s per program, 20s total) are not yet enforced; they arrive
  with the explanation path in a later Phase 2 task.
- Progress is reported as the browser's `loaded` value only; no byte total or time
  estimate is claimed.

## Handoff

```ts
import { createLocalModelAdapter, LocalModelError } from "@/client/adapters/nano";

const adapter = createLocalModelAdapter();           // inject { getModel } in tests
const state = await adapter.probe();                 // LocalModelState
const session = await adapter.createSession({        // only from a setup action
  purpose: "extraction",
  requestedByUser: true,
  signal,
  onProgress: (loaded) => {},
});
const raw = await session.prompt(text, { schema, signal });  // string, unvalidated
session.destroy();
adapter.destroyAll();                                // on reset/unmount
```

P2-02 consumes `session.prompt(text, { schema })` and owns validating the returned
string against the shared runtime contracts before any fact is shown or sent.
