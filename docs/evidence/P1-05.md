Every amount rule carries `period: "taxYear"` and `taxYear: 2025`, asserted by test. `rule.eitc.taxyear2025` has `blocksLikelyWhenUnknown: true`, so an unstated year prompts review instead of silently using 2025 figures.

## Acceptance criteria

- EITC is part of initial screening: the program file is `status: "published"` and picked up by the catalog validator.
- Tax-year ambiguity prompts review — fixture `eitc.tax_year_unknown` expects a non-`likely` label; asserted by test.
- Maximum credits never appear as guaranteed awards — the value text calls them ceilings and a test rejects "guaranteed", "approved for" and "you will get" phrasing in the value text, fallback explanation and summary lines.
- No SSNs collected: there is no SSN field in the contracts, the checklist item explicitly says not to enter it here, and tests assert no SSN-shaped string appears in the catalog or fixtures.

## Honest limits recorded

- Qualifying-child relationship, age and residency tests are not applied; only the count is used.
- Citizenship, valid-SSN and Form 2555 rules are listed as limitations, not screened.
- Special rules (military, clergy, disability) route to a referral rather than a score.
