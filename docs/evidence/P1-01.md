## Limitations

- The PRD's Fastify server and Vite dev proxy are intentionally not built. See decision 0001.
  Every later task that names `server/index.ts`, `server/routes/*` or the proxy is satisfied
  by the mapped TanStack Start equivalent.
- `test:changed`, `test:smoke`, `test:e2e`, `test:full`, `test:eval`, `data:validate` and
  `data:links` are failing stubs, not working commands. They are owned by P3-10, P3-09,
  P1-16, P1-03 and P1-17 respectively.
- The bundle scan is a grep over the built client output, not a full taint analysis. It is
  strengthened once real server modules and secrets exist (P1-11 onward).
- No device, microphone, Nano or live Jev check was attempted here; that is P1-02.
- Package manager is `bun`, so commands are `bun run <name>`, not `pnpm <name>`.
